# BOM upload inbox

Drag a BOM PDF into this folder (Add file → Upload files) and commit.
Put the project quantity in the file name: `bom4_qty50.pdf` = 50 units.

The calculator runs automatically; the answer appears in the `results/`
folder a few minutes later (summary.md has the recommended max purchase
limit; dashboard.html is the visual view).

Note: this repository is public — files here and in results/ are visible
to anyone. The repo owner has accepted this.
